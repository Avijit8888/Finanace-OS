# FinanceOS

A beautiful, production-ready personal finance management dashboard. Track income, expenses, budgets, and savings goals with a stunning glassmorphism UI.

## Features

- **Dashboard** — Overview of finances with real-time summaries
- **Transactions** — Add, edit, delete, and search income/expenses
- **Analytics** — Visual charts for spending patterns and trends
- **Goals** — Savings goals and budget tracking with progress
- **Data Management** — Export and import CSV data
- **PWA** — Installable app with offline support
- **Dark Mode** — Elegant dark theme with glassmorphism effects
- **Responsive** — Mobile-first design that works everywhere

## Quick Start

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. Or deploy to GitHub Pages for free hosting
